# Manufacturing Operational Efficiency & Downtime Analysis | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze manufacturing performance, production efficiency, and operational downtime.

## Business Objective
The objective of this project is to analyze manufacturing operations, identify production gaps, investigate downtime contributors, and highlight potential areas for operational improvement.

## Dashboard Pages

### 1. Executive Overview
- Planned vs. actual production analysis
- Monthly estimated production cost trends
- Production runs and quality metrics
- Major downtime reasons

### 2. Downtime Analysis
- Plant-wise downtime comparison
- Machine-wise downtime analysis
- Shift-wise downtime analysis
- Downtime reason analysis
- Monthly downtime trends

## Tools Used
- Power BI
- SQL
- DAX
- Data Visualization
- Business Analysis

## Key Focus Areas
- Identifying production gaps
- Understanding downtime distribution
- Identifying major downtime contributors
- Comparing operational performance across plants, machines, and shifts
- Recommending potential strategies to reduce downtime

## Recommendations
Potential improvement areas include preventive maintenance, operator training, process standardization, and monitoring recurring downtime patterns.

Recommendations are based on observed patterns and require further investigation to validate root causes.
